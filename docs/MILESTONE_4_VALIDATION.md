## Remaining acceptance and limits

Complete `DEVICE_VALIDATION_CHECKLIST.md` once toolchains/devices are available.
Native Stockfish plugin integration, Unicode piece glyphs, native network policy,
physical-device reconnect and animation performance remain unverified.

Rooms, tokens and command receipts are in-memory. Tokens survive a connection
loss while the lobby remains open, not app termination. Rematches keep colours.
There is no latency compensation, public account identity, persistence, room
expiration, rate limiting, backpressure, multi-instance routing or production TLS.
Automatic repetition/fifty-move adjudication follows the reference server policy.
The native binary's combined licence/source bundle still needs a release review.
