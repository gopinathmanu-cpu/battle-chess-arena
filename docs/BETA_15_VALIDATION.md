# Android beta 15 testing handoff

Version: `0.9.0-beta.15+30` · verified ARM64 split APK version code: `2030`.

## Included changes

- Page real online players ten at a time and load ten more on request.
- Reject abusive and obfuscated offensive Avatar IDs on client and server.
- Offer opt-in Android notifications for invitations and scheduled game starts.
- Add 3-, 5- and 10-match conquests with themed opponents and roadmap/resume flow.
- Add server-authoritative Arena Credits, a 300-credit starting balance, daily
  recovery, earned rewards, visible costs, animated balance feedback and a
  one-credit online Move Suggestion charge. Local play remains free.
- Add persistent move-based XP, win-only trophies, overall points and seven
  badge levels across local, computer, tournament, conquest and online results.
- Offer an unobtrusive optional preferred name for personalized congratulations;
  users can remain unnamed and avatar creation remains exclusive to online play.
- Retain beta 14 Home artwork browsing and all earlier beta behavior.

## Testing limitations

Physical-device installation, Android notification delivery and two-phone online
acceptance remain pending. Install over the earlier ARM64 beta without uninstalling
to preserve local saves and preferences. Online credit/discovery/invitation behavior
requires the matching server revision to be deployed; packaging this APK does not
deploy the server or upload the APK.
